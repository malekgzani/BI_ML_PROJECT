DESCRIPTION DES DATASETS

Olist E-Commerce Dataset

2.1. olist_marketing_qualified_leads_dataset.csv

Description : Informations sur les leads qualifiés par le marketing (MQL).

Colonne Description Rôle
mql_id Identifiant unique du lead Identifie le lead marketing
first_contact_date Date du premier contact Indique quand le lead a été contacté pour la première fois
landing_page_id Identifiant de la page de destination Identifie la page utilisée pour obtenir le lead
origin Source du lead Indique d'où provient le lead

Utilité : Mesurer la performance des canaux d'acquisition marketing.

2.2. olist_closed_deals_dataset.csv

Description : Informations sur les vendeurs (leads) ayant conclu un accord commercial avec Olist, faisant suite aux leads qualifiés par le marketing.

Colonne Description Rôle
mql_id Identifiant du lead marketing d'origine Relie le deal conclu au lead correspondant dans marketing_qualified_leads
seller_id Identifiant du vendeur créé suite au deal Relie le deal au vendeur dans sellers
sdr_id Identifiant du Sales Development Representative Indique qui a qualifié le lead
sr_id Identifiant du Sales Representative Indique qui a conclu la vente
won_date Date de conclusion du deal Indique quand le lead est devenu vendeur actif
business_segment Secteur d'activité du vendeur Permet de segmenter les vendeurs par domaine
lead_type Type de lead (ex. online_medium) Indique le canal ou la nature du lead
lead_behaviour_profile Profil comportemental du lead Aide à catégoriser le style du vendeur potentiel
has_company Indique si le lead possède une entreprise déclarée Qualifie le sérieux/statut légal du vendeur
has_gtin Indique si les produits ont un code GTIN Indique la maturité du catalogue produit du vendeur
average_stock Stock moyen déclaré Donne une idée de la taille de l'inventaire du vendeur
business_type Type d'activité (ex. reseller, manufacturer) Précise le modèle commercial du vendeur
declared_product_catalog_size Taille du catalogue produit déclarée Indique l'ampleur de l'offre du vendeur
declared_monthly_revenue Chiffre d'affaires mensuel déclaré Donne un indicateur de la taille économique du vendeur

Utilité : Mesurer le taux de conversion des leads en vendeurs actifs et analyser les caractéristiques des vendeurs recrutés (funnel marketing → onboarding vendeur).

2.3. olist_geolocation_dataset.csv

Description : Correspondance entre les codes postaux et les coordonnées géographiques.

Colonne Description Rôle
geolocation_zip_code_prefix Préfixe du code postal Permet de relier une position géographique à un code postal
geolocation_lat Latitude Indique la position nord-sud
geolocation_lng Longitude Indique la position est-ouest
geolocation_city Ville Indique la ville correspondant à la position
geolocation_state État Indique l'État correspondant à la position

Utilité : Réaliser des analyses géographiques et calculer des distances entre vendeurs et clients.

2.4. olist_order_items_dataset.csv

Description : Détail des articles contenus dans chaque commande.

Colonne Description Rôle
order_id Identifiant de la commande Relie l'article à sa commande
order_item_id Numéro de l'article dans la commande Identifie la position de l'article dans la commande
product_id Identifiant du produit Indique quel produit a été acheté
seller_id Identifiant du vendeur Indique quel vendeur a vendu le produit
shipping_limit_date Date limite d'expédition Indique la date limite à laquelle le vendeur doit expédier l'article
price Prix de l'article Indique le prix payé pour le produit
freight_value Frais de transport Indique le coût de livraison de l'article

Utilité : Analyser les produits vendus, les prix, les frais de livraison et les vendeurs.

2.5. olist_order_payments_dataset.csv

Description : Informations concernant les paiements des commandes.

Colonne Description Rôle
order_id Identifiant de la commande Relie le paiement à la commande
payment_sequential Numéro séquentiel du paiement Identifie l'ordre des paiements d'une commande
payment_type Type de paiement Indique le moyen de paiement utilisé
payment_installments Nombre d'échéances Indique le nombre de paiements prévus
payment_value Montant payé Indique le montant du paiement

Utilité : Analyser les méthodes de paiement et les comportements financiers des clients.

2.6. olist_order_reviews_dataset.csv

Description : Avis et évaluations laissés par les clients après leurs commandes.

Colonne Description Rôle
review_id Identifiant de l'avis Identifie l'avis client
order_id Identifiant de la commande Relie l'avis à la commande concernée
review_score Note de 1 à 5 Mesure le niveau de satisfaction du client
review_comment_title Titre du commentaire Contient le résumé ou le titre de l'avis
review_comment_message Message du commentaire Contient le commentaire détaillé du client
review_creation_date Date de création Indique quand l'avis a été créé
review_answer_timestamp Date de réponse Indique quand Olist a répondu à l'avis

Utilité : Mesurer la satisfaction et analyser l'expérience client.

2.7. olist_orders_dataset.csv 🔑

Description : Dataset central contenant les informations principales sur les commandes.

Colonne Description Rôle
order_id Identifiant unique de la commande Identifie chaque commande
customer_id Identifiant du client Relie la commande au client
order_status Statut de la commande Indique l'état actuel de la commande
order_purchase_timestamp Date et heure d'achat Indique quand la commande a été passée
order_approved_at Date d'approbation du paiement Indique quand le paiement de la commande a été approuvé
order_delivered_carrier_date Date de remise au transporteur Indique quand la commande a été remise au transporteur
order_delivered_customer_date Date de livraison au client Indique quand le client a reçu la commande
order_estimated_delivery_date Date de livraison estimée Indique la date prévue de livraison

Utilité : Analyser le cycle complet des commandes et calculer les KPI logistiques.

2.8. olist_products_dataset.csv

Description : Informations décrivant les produits disponibles sur la plateforme.

Colonne Description Rôle
product_id Identifiant unique du produit Identifie le produit
product_category_name Catégorie du produit Indique la catégorie à laquelle appartient le produit
product_name_lenght Longueur du nom Indique le nombre de caractères du nom du produit
product_description_lenght Longueur de la description Indique le nombre de caractères de la description
product_photos_qty Nombre de photos Indique combien de photos présentent le produit
product_weight_g Poids en grammes Indique le poids du produit
product_length_cm Longueur en centimètres Indique la longueur du produit
product_height_cm Hauteur en centimètres Indique la hauteur du produit
product_width_cm Largeur en centimètres Indique la largeur du produit

Utilité : Décrire les caractéristiques des produits et étudier leur impact sur les ventes.

2.9. olist_sellers_dataset.csv

Description : Informations concernant les vendeurs présents sur la plateforme.

Colonne Description Rôle
seller_id Identifiant unique du vendeur Identifie le vendeur
seller_zip_code_prefix Préfixe du code postal Permet de localiser approximativement le vendeur
seller_city Ville du vendeur Indique la ville où se trouve le vendeur
seller_state État du vendeur Indique l'État où se trouve le vendeur

Utilité : Analyser la localisation et la performance des vendeurs.

2.10. product_category_name_translation.csv

Description : Traduction des catégories de produits du portugais vers l'anglais.

Colonne Description Rôle
product_category_name Nom de la catégorie en portugais Identifie la catégorie originale
product_category_name_english Nom de la catégorie en anglais Fournit la traduction anglaise de la catégorie

Utilité : Faciliter l'analyse et la compréhension des catégories de produits en anglais.
